# AI PDF Chat App

An AI-powered PDF chatbot built using Streamlit, LangChain, FAISS, and Groq API.  
Users can upload PDF files, ask questions, generate summaries, compare multiple PDFs, and download responses as PDF files.

## Features
- Chat with uploaded PDF documents
- AI-generated PDF summaries
- Multiple PDF support
- PDF comparison
- Download responses as PDF
- Chat history support
- Modern dark UI using Streamlit

## Tech Stack
- Python
- Streamlit
- LangChain
- FAISS Vector Store
- HuggingFace Embeddings
- Groq API (LLM)
- PyPDF2
